    Réglages

    À faire une seule fois, pour que le bouton « Publier » puisse mettre le site à jour.

    Le site est rangé sur GitHub. Pour y enregistrer vos modifications, cette page a besoin d’une clé d’accès personnelle. Elle reste dans ce navigateur uniquement et ne donne accès qu’à ce site.
    1. Ouvrez github.com → Settings → Fine-grained tokens → Generate new token (connectée à votre compte GitHub).
    2. Nom : Portfolio admin. Expiration : celle de votre choix (1 an par exemple).
    3. « Repository access » → Only select repositories → choisissez le dépôt du portfolio.
    4. « Permissions » → Repository permissions → Contents : Read and write.
    5. Cliquez sur « Generate token », copiez la clé (elle commence par github_pat_) et collez-la ci-dessous.
